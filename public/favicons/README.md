# Favicons

This directory accepts the package generated by https://www.favicon-generator.org/.

Upload the generated files here, keeping their original names:

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `favicon-96x96.png`
- `android-icon-192x192.png`
- `apple-icon-57x57.png`
- `apple-icon-60x60.png`
- `apple-icon-72x72.png`
- `apple-icon-76x76.png`
- `apple-icon-114x114.png`
- `apple-icon-120x120.png`
- `apple-icon-144x144.png`
- `apple-icon-152x152.png`
- `apple-icon-180x180.png`
- `apple-icon.png`
- `apple-icon-precomposed.png`
- `ms-icon-144x144.png`
- `manifest.json`
- `browserconfig.xml`

The theme prints only tags for files that exist. If none of the generated PNG/ICO files are present, it falls back to `favicon.svg` and `site.webmanifest`.
